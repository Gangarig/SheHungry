# SheHungry

A clean web and Expo starter for finding a next meal. It ships with 20 fictional restaurants so the product can be built without a database first.

## Run it

1. Install dependencies with `npm install`.
2. Copy `apps/web/.env.example` to `apps/web/.env.local` and `apps/mobile/.env.example` to `apps/mobile/.env`.
3. Start the web app with `npm run web`, or the Expo app with `npm run mobile`.

Without the optional Supabase variables, both apps stay fully browseable in demo mode. Add them to enable email-link sign-in.
