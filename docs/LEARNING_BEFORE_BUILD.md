# SheHungry — Learning Before Build

## Goal
Learn only what is needed to build the next vertical slice.

## Before production coding
- TypeScript + React: props, state, effects, refs, composition, async code and strict types.
- Expo / React Native: core components, layout, safe areas, Expo Router, web and physical-iPhone testing.
- Gestures and animation: drag translation, velocity, thresholds, springs and responsive interaction.
- Supabase: migrations, Auth, Postgres, RLS and environment configuration.
- External APIs: requests, response normalization, errors, quotas and secure key handling.
- Google Places: current fields, pricing, attribution and data/storage rules; request only fields the product needs.
- Location: permission states, denial UX, distance calculations and the distinction between radius distance and true route/travel time.
- Git: small commits, diffs, safe reverts and keeping environment secrets out of the repository.

## Three learning spikes
1. Swipe Lab — one fixture food card swipes left/right on web and a physical iPhone.
2. Supabase Lab — a protected favourite row with RLS.
3. Places Lab — one controlled restaurant search normalized into the SheHungry Restaurant domain type.

Once these work independently, begin the production roadmap.

## Learn during later phases
Testing depth, performance profiling, accessibility, analytics/monitoring and production deployment can deepen when their implementation phase begins.
